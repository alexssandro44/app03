📝 ATIVIDADE – Sistema de Inscrição para Workshop
🎯 Objetivo

Criar um sistema simples de inscrição para um workshop que valida idade e exibe os dados enviados.

📌 Requisitos
1️⃣ Criar um formulário com:

Nome completo

Email

Idade

Curso escolhido (select)

Termo de aceite (checkbox)

2️⃣ Regras do sistema:

Enviar via POST

O evento é para maiores de 16 anos

Se:

Idade ≥ 16 → Exibir mensagem de sucesso + dados do participante

Idade < 16 → Exibir mensagem de bloqueio

Se não aceitar os termos → Não permitir inscrição
